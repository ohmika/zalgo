How it works

Uses Unicode combining marks U+0300–U+036F and beyond (768–879). Each character gets 0–N random marks stacked above/below/middle. Cleaning strips code points 768–879.

Array.from() keeps emojis intact. No jQuery, no trackers, ~12KB total.

Pro tips

• Paste any Zalgo on the right → left auto-cleans
• Craziness 0 = no effect, useful to clean
